# Ophelia R&D

_Ophelia R&D_ is an association for those interested in exploring outlying, abnormal or anomalous data.

<img width="100%" src="./assets/banner.jpg"/>

## Open Source Releases

- **Bianor (Community Edition):** High-dimensional observations mapped to visual contexts in 2D — [ophelia-rnd/bianor](https://github.com/ophelia-rnd/bianor)
- **Lilypond:** A unified *Self-Organizing Map (SOM)* visualization framework — [ophelia-rnd/lilypond](https://github.com/ophelia-rnd/lilypond) <a href="https://pypi.org/project/som-lilypond/"><img src="https://img.shields.io/pypi/v/som-lilypond?color=65264B" alt="PyPI" align="center" valign="middle"></a>
- **MiniSom Representation:** An advanced wrapper around MiniSom — [ophelia-rnd/minisom-representation](https://github.com/ophelia-rnd/minisom-representation) <a href="https://pypi.org/project/minisom-representation/"><img src="https://img.shields.io/pypi/v/minisom-representation?color=65264B" alt="PyPI" align="center" valign="middle"></a>
